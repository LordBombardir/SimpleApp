# Что делает SimpleApp?
**SimpleApp** — это высокопроизводительное кроссплатформенное графическое приложение на C++23, написанное на фреймворке [Dear ImGui](https://github.com/ocornut/imgui), с современным кастомным интерфейсом, мониторингом системных метрик в реальном времени, динамической локализацией и встроенными ресурсами.

# Возможности и управление
Приложение предоставляет интерактивный интерфейс с плавной прокруткой страниц и удобными элементами управления:
- **Кастомный TitleBar**: Кастомный TitleBar, поддерживающий нативные DWM возможности Windows 11.
- **Мониторинг системных метрик в реальном времени**: Карточки аппаратного мониторинга с индикаторами нагрузки CPU, памяти RAM и диска с интервалом обновления 1000 мс.
- **Встроенная локализация**: Динамическое переключение языков (`en_US` / `ru_RU`) с автоопределением системного языка через `GetUserPreferredUILanguages` на Windows и переменные `LANG` на POSIX.
